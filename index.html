JQL Activity Stream

A Jira Cloud dashboard gadget showing an activity stream scoped by any JQL query or saved filter.

Jira's built-in Activity Stream gadget can only be pointed at a project or a user. It cannot be filtered by JQL — a request open since 2009 as JRACLOUD-19155. This gadget does that.

  • Point it at any JQL, including filter = "My team".
  • Choose a window from 24 hours to any time.
  • Filter by status changes, assignee changes, other field changes, or all of them.
  • Noise from ranking, hierarchy and provisioning fields is filtered out; repeated and bulk edits are collapsed.

Built on Atlassian Forge. It stores nothing, sends nothing outside Atlassian, and asks for a single read-only permission.
