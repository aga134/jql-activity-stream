Page Tree Sort · Last updated 1 September 2026

1. What this app does

Page Tree Sort adds an action to a Confluence page’s menu that reorders child pages into alphabetical order — either that page’s own children, or every level below it. It changes the order of pages and nothing else.

2. Who may use it

Anyone with permission to move those pages in Confluence. Every request is made as the person using the app, so it grants no access anyone did not already have.

3. What it deliberately will not do

The app refuses to act in situations Atlassian documents as capable of losing pages, rather than proceeding and hoping:

  • It never reorders against the space root, where pages disappear from the page tree display.
  • It stops at the first move Confluence refuses. Every move is made as you, so a page you are not allowed to move simply fails and the app stops there rather than leaving a tree in neither the old order nor the new one.
  • It refuses a parent with more than 200 children rather than half-sorting it.

These refusals are intentional and are not defects.

On pages you cannot see: the result is correct for the pages you can see and untouched for any you cannot. Confluence exposes no way for an app acting as you to learn that a restricted page exists — which is what restricting it means.

4. Reordering is not reversible by the app

Confluence keeps version history for page content, not for the order of pages in a tree. The app shows the resulting order before anything moves so you can decline. Once applied, restoring the previous order means moving the pages back by hand. Please read the preview.
