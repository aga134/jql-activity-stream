Page Tree Sort

A Confluence Cloud app

Sorts a page tree A–Z for everyone, permanently — without flattening the hierarchy.

Why it exists

Confluence has a Title - A to Z option in the content tree. It is a personal view: it shows only you an alphabetical list, it flattens every page in the space to one level, and it changes nothing for anyone else.

Confluence Title - A to ZPage Tree Sort
What changesyour own viewthe actual page order
Hierarchyflattened to one levelpreserved
Who sees itonly youeveryone
Lastsuntil you remove the viewuntil new pages are added

How it works

  • Open any page’s … menu, then Apps → Sort child pages A–Z.
  • The resulting order is shown before anything moves.
  • Only the minimum number of pages move — those already in the right relative order stay put.
  • If you cannot see every child page, it refuses rather than orphaning the ones you cannot see.

Built on Forge

Runs entirely on Atlassian infrastructure. It stores nothing, sends nothing outside Atlassian, and every request is made as you — so it can never move a page you could not move by hand.
